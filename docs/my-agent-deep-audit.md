# My Agent deep audit

This is the completion gate after My Agent becomes WaveOS's role-aware operating assistant. It tests what the agent can actually read, prepare and change for owners, admins, Sales, Social Managers, Crew, DWM clients and public WaveOS users—not only what the interface claims.

The final matrix identifies each tool, allowed roles/workspaces, required entitlement, server authorization, confirmation level, resulting record, audit receipt, failure recovery and whether the feature is a real action or guidance-only. Cross-client isolation, user-edited data preservation and publish/payment/signature boundaries are release blockers.

Quality checks cover sourced answers, correct tool choice, the smallest useful follow-up question, action accuracy, duplicate prevention, latency, credit use, partial failure and safe recovery. Phone and desktop testing includes long-running requests with the shared surfer-wave status indicator.

The deliverable is a concise scorecard, verified capability matrix, P0–P3 findings and ordered improvement backlog. Missing provider credentials or live-device evidence remain explicitly unverified.
